# Rooted Commons V2.3.0

## Baserow fields used

Site Settings must contain file fields named exactly:

- Gluten Free logo
- Organic Food Federation logo

Products `Certification` may be a multi-select field. Recognised values include `Gluten Free` and `Organic Food Federation` alongside the existing certification options.

The dashboard collection-point editor writes to the existing Members field `Collection point`. No new table or environment variable is required.

## Customer-visible changes

Orders with a closing balance below £0.00 are labelled **Order reserved**. Orders at £0.00 or above are labelled **Order confirmed**. Positive orders no longer show the redundant balance reassurance.

Order references now use `RC-YYYYWW-000` format. The final three digits are checked against existing orders for the same ordering week before submission.
