# Rooted Commons V2.1.2

This release prepares the project for Baserow Batch Create Rows.

## Required code changes
- Add a `Stock Movement JSON` long-text field to the `Web Orders` table.
- During order confirmation, generate **two** server-side JSON payloads:
  - `Item JSON` (customer/order snapshot)
  - `Stock Movement JSON` (payload for Baserow Batch Create Rows)
- `Stock Movement JSON` should contain one object per stock movement using the destination field names.
- Replace the Iterator in the Baserow automation with a Batch Create Rows action:
  `from_json(New Web Order → Stock Movement JSON)`
- Keep Account Transactions and order confirmation as separate actions.

No other project files were modified automatically.
