# Rooted Commons v2.9.8 setup

## Badge assignment

Founder status is assigned once, during signup, using the same definition as the public `Total members` statistic: rows in Members where `Active = true`.

The signup endpoint already loads Members to check for duplicate email addresses, so no additional Baserow read is required.

Before the new row is created:

- current active total 0–9 → write `Founder badge = Founder 10`
- current active total 10–24 → write `Founder badge = Founder 25`
- current active total 25–49 → write `Founder badge = Founder 50`
- current active total 50+ → do not write a Founder badge

The badge is stored with the member and is not recalculated later as membership grows.

For members without a Founder badge, the dashboard uses the new Site Settings file field:

- `Member badge` — File

The old row-ID-based badge fallback has been removed.

## Dashboard layout

The top row is now a genuine two-column grid:

1. Your membership
2. Your weekly commitment

Your collection point appears beneath at the same card width rather than forcing the Membership card to full width. The layout stacks to one column on smaller screens.
