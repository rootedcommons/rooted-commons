# Rooted Commons v2.8.0 setup

## Baserow changes

### Products
Add these fields if they do not already exist:
- `May contain` — Long text
- `FBO / importer` — Long text

The product popup also uses the existing `Origin`, `Secondary origin`, `Description` / `Expanded description`, `Ingredients`, `Allergens`, `Storage`, `Nutrition basis`, `Energy kJ`, `Energy kcal`, `Fat`, `Saturates`, `Carbohydrate`, `Sugars`, `Fibre`, `Protein`, and `Salt` fields.

`Allergens` should contain the allergen names that occur in `Ingredients` (comma, semicolon or pipe separated). Matching terms are rendered bold in the popup.

### Members
Add:
- `Phone` — Single line text
- `Membership consent` — Boolean
- `Membership consent at` — Date/time
- `Marketing consent` — Boolean

The signup endpoint also uses the existing `First name`, `Last name`, `Email`, `Active`, `Order token`, `Weekly commitment`, `Collection point`, and `Member since` fields.

### Interface Content
If `Area` is a Single select, add the option `Signup` first. Then import or add the new `signup.*` rows included in `baserow-imports/13-interface-content.csv`.

### Runtime token
The token in `BASEROW_RUNTIME_TOKEN` must have permission to create rows in the Members table as well as its existing runtime permissions.

## No Baserow change required
The responsive shop controls, checkout basket label, Founder badge placement, and positive-credit payment-button behaviour are code-only changes.
