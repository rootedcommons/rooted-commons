# Rooted Commons v2.9.4 setup

## Members table

`Member number` is now a **Formula** field and should be the primary field:

```
concat('RC-', row_id())
```

The website no longer writes the member number after signup. Baserow generates it atomically with the row.

Add/confirm:

- `Email verified` — Boolean
- `Email verified at` — Date/time
- `Product requests` — Long text
- `Order token expiry` — Date/time
- `Monthly equivalent` — Number, 2 decimals
- `Contribution frequency` — Single select: `Weekly`, `Monthly`

Monthly membership commitment has a minimum of **£43.33**. Weekly remains **£10.00**. Typed amounts may include pennies; +/- controls jump between whole-pound landmarks, with £43.33 as the special monthly floor.

The runtime token needs Create and Update permission on Members. Delete permission is no longer needed for signup rollback.

## Email confirmation

Signup creates the member immediately with `Email verified = false`.

The website then sends a webhook event to:

1. `WELCOME_EMAIL_WEBHOOK_URL`, if configured; otherwise
2. `MAGIC_LINK_WEBHOOK_URL`.

Payload event: `member_signup_confirmation`.

The `link` / `verificationLink` value points to `/api/verify-email?token=...`. Opening it verifies the current member token, writes:

- `Email verified = true`
- `Email verified at = now()`

and redirects to the member dashboard.

Configure your Baserow/SMTP email workflow to use the supplied `link` as the confirmation button.

Existing members requesting a login link use `MAGIC_LINK_WEBHOOK_URL`. The request now rotates `Order token` first, so the emailed link is genuinely new and the previous link stops working immediately.

## Collection-point signup flow

Collection point is chosen first. Preferred collection day is then restricted to the days/times supported by that location.

The label line is:

`Collection point (see our map)` — *Only some locations support late collection.*

The map link preserves the in-progress signup form. On the map:
- a normal purple `Back to form` button appears above the map;
- selecting a point returns to signup and fills the Collection point field;
- an authenticated member can use `Select collection point` to update their saved point.
