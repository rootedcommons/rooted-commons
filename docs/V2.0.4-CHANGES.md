# V2.0.4 changes

- Removed the Order Submissions table and all environment/configuration references.
- Confirmed orders now always write Order Lines, signed Stock Movements and a signed Account Transaction.
- Website order Account Transactions link through `Member`; `Xero Contact ID` is left blank.
- Website transaction types are `Order charge` and `Order reversal`.
- The header button changes to `My Membership` and links to `/dashboard/` whenever a valid-looking member token is present in the URL or browser storage.
- Home rows keyed `how-1`, `how-2`, and `how-3` are grouped as the `how-it-works` card group even if one Group key is accidentally blank.
