# Rooted Commons v2.9.3 setup

## Members

Use `Member number` as the primary Single line text field. The signup endpoint creates the member first, then assigns `RC-{Baserow row ID}`.

Remove/retire `Payment reference` and `Xero ContactID` from Members.

Required signup fields:
- `Member number` — Single line text; primary
- `Order token expiry` — Date/time
- `Monthly equivalent` — Number, 2 decimals
- `Contribution frequency` — Single select: Weekly / Monthly
- `Product requests` — Long text, optional
- existing signup fields from v2.9.x

The runtime Baserow token needs Create, Update and (for rollback on a failed member-number update) Delete permission on Members.

## Account Transactions

Use:
- `Xero BankTransactionsID` — Single line text
- `Xero PaymentID` — Single line text
- `Xero Reference` — Single line text

Do not use Xero ContactID for member matching. The future/import sync matches `Xero Reference` containing `RC-x` to `Members → Member number`.

## Token expiry

A signup token is given a fallback expiry at the end of the following Sunday. The weekly Sunday token rotation should overwrite `Order token` and `Order token expiry`; overwriting the token immediately invalidates the previous link.

## Interface Content

Update/import `baserow-imports/13-interface-content.csv`. New/changed Signup keys include:
- `signup.confirm_email_label`
- `signup.collection_points_map_link`
- `signup.weekly_amount_label`
- `signup.monthly_amount_label`
- `signup.requests_heading`
- `signup.requests_prompt`
- `signup.requests_placeholder`
- the existing editable success keys `signup.success_heading`, `signup.success_message`, `signup.dashboard_button`, `signup.dashboard_security`.
