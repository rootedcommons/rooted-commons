# v2.7 setup checklist

1. Add the new Baserow fields listed in `COLLECTION_SLOTS.md` and in `baserow-table-specification/`.
2. Add `Hero button size` to Pages with options `Small`, `Medium`, `Large`; use `Large` on Home if desired.
3. Populate collection times for every active collection point using 24-hour dotted notation (for example `17.00-19.00`). Add Friday/weekend times only where bags can genuinely remain available.
4. Review every product's `Late collection` value. Missing values intentionally behave as `Thursday only`.
5. Set member preferred collection days where known; otherwise Thursday is used.
6. Add the three Web Orders collection snapshot fields before accepting orders through v2.7.1.

7. In Web Orders, make sure `Collection day` and `Collection time` are **Single line text** fields. Remove the obsolete `Fulfilment date` field.
