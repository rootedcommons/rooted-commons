# Rooted Commons v2.9.5 dashboard setup

No new Baserow fields are required for this dashboard update.

## Founder badge

The website now assigns the displayed founder badge automatically if `Founder badge` is blank:

- member row IDs 1–10 → `Founder 10`
- IDs 11–25 → `Founder 25`
- IDs 26–50 → `Founder 50`
- 51+ → normal Rooted Commons member

An explicitly stored Founder badge still overrides this automatic value.

## New-member state

A member is treated as new until Account Transactions contains at least one positive included payment for that member. New members:
- see `Welcome {name}`;
- see `Set up your regular payment`;
- do not see previous-order copy, perks, average weekly orders, recent payments, full account activity or increase-commitment prompts.

## Negative Member Credit

For credit below £0 the Membership card shows:
- amount required to return to £0;
- Bank transfer (recommended), revealing BACS details;
- Pay securely online, revealing disabled Card payment and Open banking choices ready for a future payment integration.

No online payment transaction is created in v2.9.5.

## Current weekly orders

The member API now exposes the current `Processing` or `Confirmed` Web Order for the active ordering week. The dashboard changes the market button wording accordingly.

Actual self-service editing of a confirmed/reserved order is **not enabled in v2.9.5** because the current order processor intentionally blocks a second order and the Baserow stock/ledger automation is create-only. See `ORDER_EDIT_DESIGN.md` for the recommended safe design.

## Interface Content

Update/import `baserow-imports/13-interface-content.csv`. The new Dashboard keys cover greetings, negative-credit payment choices, order-state buttons, perks/countdowns, collection messages, bank-detail labels, new-member payment setup and system messages.
