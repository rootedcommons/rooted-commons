# Rooted Commons v2.9.7 setup

## Members fields

The current signup/token fields are:

- `Member since` — Date/time. Signup writes the membership acceptance/join timestamp. The dashboard uses this same field to calculate membership weeks.
- `Membership consent` — Boolean.
- `Token created` — Date/time. Written every time an Order token is generated.
- `Order token` — Single line text.
- `Order token expiry` — Date/time.

`Membership consent at` is no longer used anywhere.

## Token cycle

Every token generated by the website follows the same Europe/London rule:

- before Wednesday 18:05 → expires that Wednesday at 18:05;
- at or after Wednesday 18:05 → expires the following Wednesday at 18:05.

This handles GMT/BST automatically.

When a token is generated, write:

- `Token created = exact generation timestamp`
- `Order token expiry = next applicable Wednesday 18:05`

The scheduled weekly email process should renew each active member's token at Wednesday 18:05 and send that newly generated token. Replacing `Order token` immediately invalidates the previous link.

## Signup layout

The highlighted internal signup boxes introduced in v2.9.4 have been removed. Collection details, Weekly commitment, Requests and Keeping in touch again use thin section dividers.

The newsletter consent checkbox and Membership Terms/Privacy consent checkbox remain adjacent, with no section divider between them.
