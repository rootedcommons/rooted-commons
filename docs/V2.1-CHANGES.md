# V2.1 changes

- Website creates only a validated Web Orders row.
- Removed Order Lines, replacement orders, release movements and order reversals.
- Removed runtime Stock Movement and Order Lines table variables.
- Browser sends only product IDs and quantities.
- Server stores an authoritative basket snapshot using Baserow prices.
- `/api/products` now returns live Member price as well as availability.
- `/orders/` and checkout refresh displayed prices at runtime.
- Baserow automation owns Stock Movement, Account Transactions, confirmation status and email.
