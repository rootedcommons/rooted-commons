# Rooted Commons v2.5.0

## Product cards

- Product name is followed by `Origin` and `Secondary origin`.
- Pack amount is left aligned above the certification logos.
- Price is centred above the quantity selector using layout alignment rather than literal spaces.
- Certification logos sit at the lower left, level with the quantity selector.

## Product information popup

- Removed the public `Why we stock it` panel.
- Shows one main description (`Expanded description`, falling back to `Description`).
- Added `Crop info` and `Packaging and disposal` sections.
- Added a compact nutrition table that remains hidden until at least one nutrition value is populated.

## Baserow documentation

- Added a complete `baserow-table-specification` folder documenting the fields currently used across every table.
- Added `baserow-updates/19-product-card-and-nutrition-fields.csv` for the new product fields.
